- B2B-мониторы. Отвечал за создание и производство упаковки, выстроил взаимодействие R&D, продакт-менеджеров и внешних контрагентов.
- Серверная стойка и продуктовый дизайн. Помогал в разработке безеля для серверной стойки, поддерживал старшего менеджера проектов.
- Поставщики и затраты. Скоринг поставщиков, сравнение КП, расчёт unit-экономики.
